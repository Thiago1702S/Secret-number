# 🎯 Jogo do Número Secreto

Projeto simples desenvolvido em **JavaScript** para praticar conceitos fundamentais de lógica de programação.

O objetivo do jogo é descobrir um número secreto gerado aleatoriamente entre **1 e 10**.

## 🚀 Jogar online

O projeto está publicado no GitHub Pages e pode ser executado diretamente pelo navegador.

👉 [Jogar Número Secreto](https://thiago1702s.github.io/Secret-number/)

## 🎮 Como funciona

Ao iniciar o jogo, um número secreto é gerado aleatoriamente.

O jogador informa seus palpites e recebe dicas:

- Se o número secreto é maior que o palpite
- Se o número secreto é menor que o palpite
- Quantidade de tentativas até acertar

Ao encontrar o número correto, o jogo informa o número secreto e quantas tentativas foram necessárias.
